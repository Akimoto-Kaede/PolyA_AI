## 当前状态与下一步工程化

本项目已有真实历史输出与多条实验路线，尚未整理为可一键复现的训练框架。按下面顺序推进，能比继续堆叠模型更明确地检验研究结论：

1. **评估协议**：固定且保存按 gene/transcript 或染色体分组的 train/validation/test ID；仅在训练集拟合 scaler，区分选模验证与最终测试。
2. **统一基线**：同一 split 上比较常数/均值、3-mer + RF、CNN-GRU、Transformer 和 DNABERT-2，统一 nt/变换空间及指标定义。
3. **结果复算**：修正 CPM 区段变量引用，重新计算表格、样本数、MAE、相关性和分布指标，补多随机种子与置信区间。
4. **训练入口**：将绝对路径、超参数和输出目录移到配置；使用 main 入口；避免 import 即训练；补小规模数据 smoke test。
5. **可复现交付**：记录模型/数据版本、完整依赖环境和 GPU 信息；提供经授权的小示例数据、结果汇总与可执行的最小 demo。
